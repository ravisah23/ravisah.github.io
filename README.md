## 🚀 Running Locally

Install Ruby and Bundler, then install the project dependencies:

```bash
bundle install
```

Run the Jekyll development server:

```bash
bundle exec jekyll serve
```

Open the local website at:

```text
http://localhost:4000
```

The site will automatically rebuild when changes are made to the project files.

---

## 🚀 Deployment

The portfolio is designed to be deployed using **GitHub Pages**.

After pushing the repository to GitHub:

1. Open the repository's **Settings**.
2. Go to **Pages**.
3. Select the appropriate branch.
4. Select the root folder if required.
5. Save the configuration.
6. GitHub Pages will build and publish the Jekyll website.
